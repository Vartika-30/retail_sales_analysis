# Retail Intelligence Dashboard

**Turning Retail Transaction Data into Actionable Business Insights**

## Project Overview

The Retail Intelligence Dashboard is a data analytics project focused on understanding retail sales performance, product demand, customer purchasing behaviour, and geographic revenue distribution.

Using the Online Retail dataset from the UCI Machine Learning Repository, this project transforms raw transactional data into meaningful business insights through data cleaning, exploratory data analysis (EDA), Python visualizations, and dashboard development.

The goal is to demonstrate how data analytics can help businesses identify sales trends, understand customer loyalty, evaluate product performance, and make data-informed decisions.

## Business Problem

Retail businesses generate large volumes of transaction data, but raw data alone does not explain what drives revenue or how customers behave.

This project explores five key business questions:

- How does revenue change over time?
- Which products generate the most revenue?
- Which countries contribute the most to sales?
- What proportion of identified customers make repeat purchases?
- How can these insights inform customer retention and sales strategies?

## Dataset

**Source:** [UCI Machine Learning Repository — Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail)
